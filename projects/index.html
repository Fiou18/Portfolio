PROJETS

Un système.
Plusieurs problèmes.

N.O.X. est le projet principal : un agent IA compagnon expérimental conçu pour partager une activité avec son utilisateur. Pour y parvenir, je traite séparément les problèmes de perception, de cognition, de présence et, à terme, d'action.

PROJET PARENT · N.O.X.

Percevoir ce qui se passe.
Conserver ce qui compte.
Décider quand intervenir.

L'objectif n'est pas seulement de faire répondre un modèle. N.O.X. explore comment un agent peut suivre une activité, maintenir un contexte, arbitrer ses interventions et manifester une présence dans l'environnement numérique qu'il partage avec l'utilisateur.

CONCEPT · NON PROTOTYPÉ
TRAJECTOIRE Percevoir → comprendre → décider → agir → observer les conséquences.

La présence relie cette boucle à l'utilisateur. L'action reste aujourd'hui un axe de recherche, pas une capacité annoncée.
