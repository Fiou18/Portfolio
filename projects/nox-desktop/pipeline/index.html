PRÉSENCE · 03 · PIPELINE

SORTIR N.O.X. D'UNREAL.

Comment conserver un rendu temps réel avec transparence pour que N.O.X. puisse être composité ailleurs ?

PROBLÈME TECHNIQUE

Un fond noir n'est pas de la transparence.

Pour devenir une présence de bureau ou de stream, le rendu Unreal doit sortir avec un alpha exploitable. Le chantier porte donc sur toute la chaîne : rendu, canal alpha, transport GPU et composition finale.

UNREAL→RGBA→SPOUT / GPU→COMPOSITE→OVERLAY / OBS

VALIDATION

Le pipeline RGBA devient une brique indépendante.

ALPHA

Transparence validée

La silhouette et les particules peuvent être extraites sans fond opaque.

GPU

Transport temps réel

Le rendu reste dans une chaîne adaptée au temps réel plutôt qu'à l'export vidéo.

COMPOSITION

Shader / mélange

La sortie est pensée pour être recomposée dans différents environnements.

RÉUTILISATION

Une sortie, plusieurs surfaces

Desktop, OBS et futures intégrations peuvent consommer la même présence.

Jalon validé dans le projet : pipeline RGBA et prototype d'overlay desktop documentés dans le repo N.O.X.
À ajouter : capture dédiée du transport Spout / composite shader. Le média ci-dessus prouve la sortie alpha obtenue, pas à lui seul l’intégralité du transport GPU.
